# Rulegate check

Fail a pull request when the AI-agent instruction files generated by
[Rulegate](https://github.com/sayansr26/rulegate) — `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`,
`.cursor/rules/*.mdc`, `.github/copilot-instructions.md` and the rest — have drifted from the
canonical source in `.rulegate/`, and mark every drifted region **inline on the diff**.

```yaml
# .github/workflows/rulegate.yml
name: rulegate
on: [pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: sayansr26/rulegate-action@v1
```

| input               | default           |                                             |
| ------------------- | ----------------- | ------------------------------------------- |
| `working-directory` | the checkout root | where to check, for a monorepo subdirectory |
| `annotations`       | `true`            | set `false` for the log output only         |

It runs the same `rulegate check` as the CLI — one rendering pass, one verdict — so the
annotations and the log cannot disagree. It is read-only, needs no permissions beyond the
default `contents: read`, and makes no network calls.

A repository that does not use Rulegate yet starts with `npx rulegate@latest init`, which
prints what it would do and writes nothing without `--yes`.

This repository holds the published Action only. Its source, tests and issues live in
[sayansr26/rulegate](https://github.com/sayansr26/rulegate) under `action/`; the files here are
generated from there on each release.
